# ASE230 School Website Project

This is a school website that lets students and teachers manage classes online.

## What it does:
- Students can sign up and join classes
- Teachers can create and manage classes  
- Everyone can see their profile and classes
- Safe login system with tokens

## How to use:
1. Set up your database using `database_schema.sql`
2. Update `config/db.php` with your database info
3. Start your web server
4. Visit `http://localhost:8080/api/` to see all features

## Testing:
- Use the files in `/tests/curl/` to test everything
- Or use the web page at `/tests/html/api_test_suite.html`
